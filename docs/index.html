VerificationVerifica

What stands behind each download.Che cosa garantisce ogni download.

A download is worth installing only if it can be checked. These three rules hold for every file on this page. Un download merita di essere installato solo se si può verificare. Queste tre regole valgono per ogni file di questa pagina.

Signed and notarized on macOSFirmati e notarizzati su macOS

macOS downloads are signed with the Apple Developer ID of G&G Technologies and notarized by Apple.I download per macOS sono firmati con l'Apple Developer ID di G&G Technologies e notarizzati da Apple.

A checksum for every fileUn checksum per ogni file

Each file is published with its SHA-256 checksum, both on this page and next to the file in its release.Ogni file è pubblicato con il suo checksum SHA-256, in questa pagina e accanto al file nella sua release.

A release never changesUna release non cambia mai

A published file is never replaced. A correction always comes out as a new version.Un file pubblicato non viene mai sostituito. Una correzione esce sempre come nuova versione.

Checking a downloadVerificare un download

Download the .sha256 file found next to the app in its release, then run this command in the folder that holds both files. Si scarica il file .sha256 che si trova accanto all'app nella sua release, poi si esegue questo comando nella cartella che contiene i due file. 

shasum -a 256 -c <file>.sha256

Automatic updatesAggiornamenti automatici

The Titanium apps look for their updates on this site, and verify each download before installing it. The check sends no information about the user or the computer. Le app Titanium cercano i propri aggiornamenti su questo sito e verificano ogni download prima di installarlo. Il controllo non invia alcuna informazione sull'utente o sul computer.
